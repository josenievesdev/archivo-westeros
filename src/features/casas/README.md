# Feature: casas

## Objetivo

Explicar identidad, territorio, jerarquía y miembros de cada casa de forma conectada
con personajes y conflictos.

## Alcance

- Listado y ficha individual.
- Región, lema, títulos, asientos y armas ancestrales.
- Señor actual, heredero, casa superior, ramas y casas juramentadas.
- Miembros y relaciones políticas.

## Datos requeridos

An API of Ice and Fire proporciona la base estructural mediante referencias. El
proyecto deberá resolverlas y complementar heráldica, periodos históricos, imágenes y
cambios por episodio.

## Ideas futuras

Mapa de influencia, árbol de vasallaje, evolución del liderazgo, piezas heráldicas y
ambiente propio opcional.

## Estado

Disponible una lista inicial, una ficha mínima y hooks de lista/detalle. La UI todavía
no resuelve referencias a personas ni otras casas.
