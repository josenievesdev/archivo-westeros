# Feature: inicio

## Objetivo

Presentar el propósito del producto y ofrecer entradas rápidas a las consultas más
útiles sin asumir todavía una dirección visual definitiva.

## Alcance

- Landing principal.
- Navegación hacia personajes y casas.
- Confirmación visible de la conexión con la fuente de datos.
- Descubrimiento futuro de contenido seguro para el progreso del usuario.

## Datos requeridos

Muestras pequeñas de personajes y casas. Más adelante podrá usar preferencias de
spoilers, historial reciente y contenido editorial destacado.

## Ideas futuras

Continuar la última consulta, sugerir relaciones relevantes para el episodio actual y
adaptar el ambiente sin revelar eventos posteriores.

## Estado

Implementación temporal disponible. Muestra el nombre provisional, enlaces básicos y
el resultado de dos consultas mediante TanStack Query.
