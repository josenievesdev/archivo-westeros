# Feature: cronología

## Objetivo

Ordenar acontecimientos y cambios para comprender la evolución de personajes, casas,
lugares y conflictos.

## Alcance

- Línea temporal por recurso o tema.
- Eventos narrativos, políticos y militares.
- Cambios de estado, lealtad, ubicación y liderazgo.
- Filtrado estricto según el progreso de spoilers.

## Datos requeridos

Eventos editoriales con orden, participantes, ubicación, fuente y punto de revelación.
La API pública no ofrece granularidad por episodio.

## Ideas futuras

Comparar dos cronologías, saltar del evento al mapa y reproducir la evolución de una
guerra en la mesa estratégica.
