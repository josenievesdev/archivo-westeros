# Feature: mapa

## Objetivo

Dar contexto geográfico a lugares, casas, viajes, eventos y batallas de Westeros.

## Alcance

- Mapa interactivo por regiones y lugares.
- Capas de casas, rutas, conflictos y eventos.
- Navegación entre mapa, fichas y cronología.
- Visibilidad adaptada al Spoiler Shield.

## Datos requeridos

Geometrías o coordenadas con licencia adecuada, jerarquía de regiones, nombres,
periodos y relaciones con otros recursos. La fuente actual no proporciona un modelo
cartográfico completo.

## Ideas futuras

Recorridos de personajes, comparación temporal, clima ambiental y transición directa
a una batalla o casa seleccionada.

## Estado

Ruta `/mapa` preparada con placeholder. No se ha seleccionado motor de mapas ni fuente
cartográfica.
