# Assets importados

Recursos que necesitan pasar por el grafo de Vite, por ejemplo ilustraciones usadas
desde un componente. Los archivos públicos con una ruta estable pertenecen a
`public/`.

Antes de añadir imágenes, audio o tipografías se debe registrar origen, licencia y
uso previsto. No se almacenan aquí recursos provisionales sin esa información.
