## Cómo mantenerla

- Actualizar el estado de una idea cuando pase a implementación.
- Registrar una decisión cuando cambie una frontera, fuente de datos o dependencia
  importante.
- Evitar presentar conceptos futuros como capacidades disponibles.
- Mantener nombres propios y términos del universo según las reglas de localización.
